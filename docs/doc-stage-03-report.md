## 8. אימות ידני בדפדפן

שלוש ריצות ב-Chromium, מפני שמערך הבדיקות מריץ DOM מינימלי ולא דפדפן:

1. **הקוד מ-Localhost**: הפאנל נטען מהאחסון, אישור פריט כתב רשומה, ורענון הדף הראה את המצב החדש. שתי תקלות נמצאו כאן ותוקנו: הודעת האישור נמחקה בטעינה שאחריה, ולשדה covers_content_contribution לא היה פקד והוא נכתב false בשקט.
2. **מסך בעלת הפרויקט**: M-06 = 0 לפני הרישום, טופס ריק נדחה בשדה המכון, רישום מלא נשמר, ו-M-06 = 1 אחריו.
3. **הקובץ הארוז ב-file://**: 183KB, נפתח בלחיצה כפולה, אותה התנהגות, בלי שגיאות בקונסולה. יעד ההרצה של decision-04 עומד.
