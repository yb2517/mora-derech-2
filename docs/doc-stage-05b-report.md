## 6. סטיות מהתוכנית, וחוב טכני

1. **שדות זמן הם text ולא timestamptz** (הכרעה ב6 אמרה timestamptz). הסיבה: המודולים כותבים חותמות ISO ומשווים אותן כמחרוזות, ו-timestamptz היה מחזיר אותן בצורה אחרת, כלומר הדרייבר לא היה מחזיר את מה שהמודול כתב. רשום במיגרציה. סטייה קטנה בטיפוס, לא בשדות.
2. **הסשן הזה אינו מגיע לכתובת הספק.** מדיניות הרשת של סביבת Claude Code חוסמת את supabase.co (הפרוקסי עונה 403), ולכן שלוש פעולות שתוכננו דרך הרשת נעשו אחרת או ממתינות: הזריעה של המסד החי נעשתה ב-SQL דרך כלי הניהול (אותם נתונים, אותן ספירות, מסומנים is_demo; הסקריפט הוא הדרך החוזרת ואומת מול מסד מדומה); בדיקת העשן החיה טרם רצה מול המסד החי; והעלאת הקובץ לדלי היא פעולתך. התיקון: להתיר את הדומיין *.supabase.co במדיניות הרשת של הסביבה, ואז `node tools/seed-cloud.js` ובדיקת העשן רצים מכל סשן. זו הגדרה של הסביבה, לא של הקוד.
3. **שורות בדיקת העשן אינן is_demo.** הבדיקה יוצרת פריט בשם smoke-test במסלול ההדגמה דרך create_item, ו-BE-05 אינו מסמן is_demo (אין לו שדה כזה ב-payload, ואין להמציא). ניקוי שלב 7 צריך למחוק גם שורות שמסלולן הוא מסלול הדגמה, ולא רק שורות is_demo. לרישום בתוכנית שלב 7.
4. **המפתח שבבלוק הוא המפתח הציבורי** של הספק, המיועד לדפדפן, כפי ש-decision-05 קובע. כל מי שמחזיק את הקובץ הארוז יכול לכתוב לטבלאות בגבולות המדיניות. הסיכון רשום ב-decision-05 סעיף 4 ומקובל ל-v1.
5. **מכשיר שני נראה אחרי refresh בלבד** (הכרעה ב3). נקודת הכניסה קוראת refresh בעלייה בלבד; קריאה בכל פתיחת מסך תיכנס כשיהיה מסך שנפתח ונסגר, והיום ארבעת המסכים מוצגים יחד. לרישום.
6. audit_log גדל בשתי שורות לכל בקשה, גם בענן. הגבלת גודל או ארכוב אינם במפה, ולכן אינם כאן.
7. **האירוח אינו יכול לשבת אצל הספק** (הכרעה ב7 קבעה דלי, ונקבה ב-GitHub Pages כחלופה). הדלי מגיש HTML כטקסט לפי התיעוד, ופונקציית קצה מוגשת בארגז חול שחוסם סקריפטים. decision-05 סעיף 1 כותב שהספק מכסה גם את "הכתובת לטלפון", וזה אינו נכון עוד: המסד נשאר אצל הספק, והקובץ הארוז נזקק למארח סטטי אחר. נרשם כפער 61, הכרעת פלטפורמה של בעלת הפרויקט, ומתוקן ב-decision-05 בפרומפט 4 של חלק ב. הדרייבר, האריזה והמסד אינם מושפעים: הקובץ הארוז פונה למסד לפי הכתובת שבבלוק ההגדרות, מכל מארח.

הקובץ הארוז עם בלוק הגדרות שמצביע על מסד מדומה מקומי נפתח ב-Chromium מ-file://. תשעה פאנלים עלו, אחסון הדפדפן נשאר ריק (0 מפתחות), 12 בקשות GET בעלייה, סשן נפתח עם הדגלים simulator ו-no_hebrew_voice ונרשם במסד, pushed בתחנה הראשונה נרשם, 30 שורות audit_log במסד בצורת from_module ו-outcome, הסשן נסגר במסד בסיום הטיול, ואפס שגיאות בקונסולה. מול המסד החי: ממתין להעלאה לדלי ולאימות בטלפון.

## נספח א: מקור פונקציית הקצה app (ניסיון שנכשל, לתיעוד)

הועלתה בכלי הניהול של הספק, בלי אימות JWT. שער הפונקציות מגיש את תשובתה בארגז חול שחוסם סקריפטים, ולכן היא אינה פותרת את האירוח. נשארת כאן לתיעוד הניסיון, ותוסר מהפרויקט עם הכרעת פער 61.

```ts
import "jsr:@supabase/functions-js/edge-runtime.d.ts";

const BUCKET = "app";
const DEFAULT_FILE = "mora-derech-2-cloud.html";

Deno.serve(async (req: Request) => {
  const parts = new URL(req.url).pathname.split("/").filter(Boolean);
  const name = parts.length > 1 ? parts.slice(1).join("/") : DEFAULT_FILE;
  if (!/^[\w.-]+\.html$/.test(name)) {
    return new Response("Not found", { status: 404 });
  }
  const base = Deno.env.get("SUPABASE_URL");
  const upstream = await fetch(`${base}/storage/v1/object/public/${BUCKET}/${name}`);
  if (!upstream.ok) {
    return new Response("Not found", { status: 404 });
  }
  const body = await upstream.arrayBuffer();
  return new Response(body, {
    headers: {
      "Content-Type": "text/html; charset=utf-8",
      "Cache-Control": "no-cache",
    },
  });
});
```

## 9. הצהרה: מה לא השתנה

- **ה-Repository לא השתנה**: repository/index.js זהה ל-main. אף מודול, מסך או מתאם לא השתנה. הליבה נגעה בקובץ אחד חדש, driver-cloud.js, ב-Commit מסומן.
- **רשימת קודי השגיאה נשארה 23 קודים.** לא נוספה שורה לרשימת המותר, לא נוסף מודול, לא נוספה פעולה ולא נוסף שדה לישות.
- **החוקים העסקיים לא השתנו.** פער 58 מבקש ניסוח, לא כלל.
- **דרייבר הדפדפן נשאר** לפיתוח ולבדיקות, והמערך רץ עליו כמו קודם.

זהו תוצר חלק ב. המיזוג ל-main ממתין לאישורך; פערים 58 עד 60 ממתינים לפרומפט 4; ההעלאה לדלי והאימות בטלפון ממתינים לך; פתיחת הדומיין במדיניות הרשת מאפשרת את בדיקת העשן החיה.
