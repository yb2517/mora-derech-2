# doc-error-human-text: הנוסחים לבני אדם של קודי השגיאה

סטטוס: מאושר, גרסה 1, לפי יומן 14. סוגר את הכרעה פתוחה 1 במפת המודולים גרסה 3.
תאריך: 13.09.2026
היעד: טבלת ה-reference, מפתח error_human_text, לפי המצגת חלק א: הקוד וההסבר למפתח בקוד; ההסבר לבני אדם בטבלה, בידי בעלת הפרויקט, שינוי הוא עריכת תא.
המקור לרשימת הקודים: doc-module-map גרסה 3, סעיף 4.5. 22 קודים, ובנוסף שני נוסחים שאינם שגיאה ודורשים את אותה הכרעה.

## עקרונות הניסוח, שנקבעו כאן

1. **מי קורא**: שלושה קהלים שונים. החוקר ובעלת הפרויקט על מסך ניהול, וצוות התוכן במסך התוכן, יכולים לקבל משפט שמסביר מה קרה ומה לעשות. המשפחה בשטח שומעת בקול, ולכן הנוסח שלה קצר, בלי מונחים, ואומר מה עושים עכשיו. עמודת "הקהל" מסמנת.
2. **שני משפטים לכל היותר**: מה קרה, ומה לעשות. בלי שם הקוד, בלי מילים כמו "מעטפה", "רשימת מותר" או "פונה".
3. **הבחנה בין "אסור" ל"טרם נקבע" ל"נכשל"**: שלוש משפחות ניסוח. אסור: "הפעולה אינה זמינה מכאן". טרם נקבע: "הגדרה חסרה, פנו למנהל המערכת". נכשל: "לא הצלחנו לשמור, נסו שוב".
4. **שגיאה שהמשפחה לעולם לא רואה** נשארת בטבלה עם נוסח למנהל בלבד, כי מסך הניהול עלול להציג אותה.
5. אין אשמה, אין סימני קריאה, אין "אופס".

|---|---|---|
| E-FROM-MISSING | מנהל | הבקשה הגיעה בלי זיהוי של המסך ששלח אותה, ולכן לא טופלה. רעננו את המסך ונסו שוב. |
| E-FROM-UNKNOWN | מנהל | המסך ששלח את הבקשה אינו מוכר למערכת. פנו למנהל המערכת. |
| E-ALLOW-DENIED | מנהל | הפעולה הזאת אינה זמינה מהמסך הזה. |
| E-ENVELOPE-INVALID | מנהל | הבקשה חסרה פרט נדרש ולא טופלה. רעננו את המסך ונסו שוב. |
| E-AUDIT-WRITE-FAILED | מנהל | לא הצלחנו לרשום את הפעולה ביומן, ולכן היא לא בוצעה. נסו שוב בעוד רגע. |
| E-TRANSITION-DENIED | מנהל | אי אפשר להעביר את הפריט למצב הזה ממצבו הנוכחי. |

| E-ANCHOR-OUT-OF-BOUNDS | מנהל | הנקודה שהוזנה נמצאת מחוץ לגבולות המסלול. בדקו את הקואורדינטות. |
| E-APPROVAL-WRITE-FAILED | מנהל | לא הצלחנו לשמור את ההחלטה, ולכן מצב הפריט לא השתנה. נסו שוב. |
| E-LOCK-REFUSED | מנהל | המסלול אינו מוכן לנעילה. הפריטים והתחנות שחסרים מופיעים ברשימה. |
| E-GATE-CLOSED | משפחה, מנהל | המסלול עדיין אינו פתוח לטיול. |

| E-RETRIEVAL-FAILED | משפחה | יש תקלה זמנית, ואני לא יכול לענות כרגע. נסו שוב בעוד רגע. |
| E-REF-EMPTY | מנהל | הגדרה חסרה במערכת: [שם ההגדרה]. פנו למנהל המערכת. |
| E-SESSION-CLOSED | מנהל | הטיול הזה כבר הסתיים, ולא ניתן להוסיף אליו רשומות. |
| E-LOG-TYPE-INVALID | מנהל | רשומה מסוג שאינו מוכר, או ממקור שאינו מורשה לרשום אותה. הרשומה לא נשמרה. |
| E-LOG-WRITE-FAILED | מנהל | חלק מרשומות הטיול לא נשמרו. הטיול מסומן כחלקי ולא ייספר במדדים. |
| E-NO-HEBREW-VOICE | משפחה | במכשיר הזה אין קול עברי, ולכן התשובות יופיעו בכתב. |
| E-SPEECH-NOT-RECOGNIZED | משפחה | לא שמעתי. אפשר לשאול שוב. |
| E-MIC-NOT-ALLOWED | משפחה | אין הרשאה למיקרופון. אפשר להקליד את השאלה. |
| E-LOCATION-NOT-ALLOWED | משפחה | אין הרשאה למיקום, ולכן התוכן לא ייפתח מעצמו. עדיין אפשר לשאול שאלות. |
| E-NO-EXIT-POINT | מנהל | למסלול הזה אין נקודות יציאה רשומות. הוסיפו לפחות אחת לפני שהמסלול יוצא לשטח. |

## שני נוסחים שאינם שגיאה

| המפתח | הקהל | הנוסח | מעמד |
|---|---|---|---|
| fallback_text | משפחה | אין לי מידע מאומת על זה במסלול הזה. | ננעל בבנייה 01, עובר מהקוד לטבלה. לא שונה |
| unavailable_text | משפחה | המערכת אינה זמינה כרגע. נסו שוב בעוד רגע. | חדש. שונה מנוסח ההימנעות בכוונה: זו תקלה, לא היעדר מידע |

## הערות

- שני הנוסחים עם משתנה ([שם השדה], [שם ההגדרה]) הם תבניות; הערך מוזרק מ-data של מעטפת התשובה.
- E-GATE-CLOSED נשמע למשפחה רק במצב פיתוח כשהאכיפה דולקת; במצב ייצור המסך פשוט לא נפתח, והנוסח מוצג למנהל.
- E-RETRIEVAL-FAILED ו-unavailable_text כמעט זהים בכוונה: הראשון הוא כשל בשליפה בלבד, השני כשל כללי. אם תעדיפי נוסח אחד לשניהם, זה לגיטימי, וזו עריכת תא.
