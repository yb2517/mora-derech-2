## 4. פער 88: מפתח reference חדש, בדרך למסד החי ולדפדפן

**מה נמצא**, בשאילתה לקריאה בלבד, 27.09.2026: בטבלת reference במסד החי 31 מפתחות, ו-speech_substitutions אינו ביניהם. מתאם הקול בשלב 8 דורש אותו (מפה 2.4: "מפתח חסר: E-REF-EMPTY ואין השמעה מומצאת"), ודרייבר הענן קורא את טבלת ה-reference מהמסד. **לכן מיזוג של שלב 8 בלי המפתח במסד משתיק את הקול בכתובת הציבורית.** זה נכון לכל מפתח שיתווסף בעתיד.

אף מסמך אינו אומר איך מפתח חדש מגיע למסד החי. מפה 2.1 (רשומת המסלול, פער 65) אומרת שמפתחות ה-reference נזרעים מחוץ לזמן ריצה, בידי בעלת הפרויקט או בכלי ייבוא; tools/import-corpus.js אכן מוסיף מפתחות חסרים ואינו דורס קיימים, ועשה זאת ב-25.09.2026. אבל מסמך הבנייה סעיף 3 מתאר את הפריסה כאריזה ב-Actions בכל דחיפה ל-main, ואינו מזכיר את המסד.

ובדפדפן: דרייבר הדפדפן זורע גם את טבלת ה-reference פעם אחת. דפדפן שהריץ את המערכת מקומית לפני שלב 8 נשאר בלי speech_substitutions, והקול שם שותק. טבלת ה-reference, בשונה מטבלאות CORE-03, נכתבת בזמן ריצה (set_enforce של BE-06), ולכן אי אפשר לזרוע אותה מחדש כולה.

**מוצע (א)**, מסמך הבנייה סעיף 3, משפט אחרי פסקת משתני הסביבה:

> מפתח חדש בטבלת ה-reference מגיע למסד החי **לפני** המיזוג שפורס קוד שקורא אותו: הרצת tools/import-corpus.js עם שני משתני הסביבה מוסיפה מפתחות חסרים ואינה דורסת מפתח קיים (מפה 2.1, רשומת המסלול). בלי זה הקוד החדש מקבל E-REF-EMPTY בכתובת הציבורית (פער 88).

**מוצע (ב)**, להכרעתך, שינוי ליבה בקומיט נפרד ומסומן: דרייבר הדפדפן מוסיף בכל טעינה מפתחות reference שחסרים באחסון מהזריעה, ואינו דורס מפתח קיים. זה אותו כלל של כלי הייבוא במסד. ההמלצה: כן, מאותו טעם של פער 86. החלופה: מגבלה של הרצה מקומית, שנרשמת ברישום, וניקוי אחסון הדפדפן ידני.
